# VoiceGuard (Dhawni Rakshak)

Real-time detection and prevention of voice-cloning impersonation attacks on phone and VoIP
calls, built for Indian banking contact centres.

> **Detection is advisory, never authoritative.** VoiceGuard adds friction and triggers
> out-of-band verification (call-back, step-up). It is never the sole gate on a transaction.
> **The strongest defences are partly non-acoustic.** Speaker verification, transaction
> context, conversation intent and an enforced call-back still work when the audio detector
> is fooled.

## How it works

Five independent layers, fused into one calibrated risk score and turned into a plain
instruction for the agent:

1. synthetic-voice detection;
2. speaker verification;
3. a liveness challenge;
4. conversation intent;
5. a policy with call-back.

Everything runs on the bank's premises, with no audio stored by default and no data sent to
external services. Architecture: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Try it in 2 minutes (no data, no GPU)

```bash
pip install -e ".[dev]"
python scripts/dev_gateway.py              # console at http://localhost:8765/ui/ (dev key printed)
python scripts/replay_calls.py --gateway http://localhost:8765 --tenant demo \
    --api-key vg_dev_local_console_key_0000 --calls 4
python scripts/demo_scenarios.py           # the demo scenarios, layer by layer
```

With untrained heads the acoustic layer **abstains** (it says it cannot judge). It never
invents a score. Model training and data setup are listed in
[`docs/SETUP_PENDING.md`](docs/SETUP_PENDING.md).
